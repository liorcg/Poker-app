# Poker Night

An Android app for running home poker games: add players, track buy-ins and
rebuys, enter final chip counts, and see who pays whom.

## Get the app

Download the latest APK on your phone:
https://github.com/liorcg/Poker-app/releases/latest/download/poker-app.apk

A new APK is built automatically by GitHub Actions on every push to `main`.

## Develop

Built with Flutter. `flutter run` to try it, `flutter test` to run tests,
`flutter build apk --release` to build an APK locally.
